# پنل ادمین صمت — نسخه‌ی دسکتاپ ویندوز (Electron)

این پوشه هیچ منطق تجاری جدیدی ندارد — فقط همان build وب پروژه‌ی اصلی (`samat-admin`) را داخل یک
پنجره‌ی بومی ویندوز نشان می‌دهد (از طریق یک سرور محلی express، نه `file://`، تا رفتار دقیقاً مثل
مرورگر واقعی باشد و هیچ تفاوتی بین نسخه‌ی وب و دسکتاپ نباشد).

## ساخت نصاب ویندوز (.exe)

```bash
# ۱. اول پروژه‌ی اصلی وب را build بگیرید (اگر قبلاً نگرفته‌اید)
cd ../          # به پوشه‌ی samat-admin برگردید
npm install
npm run build   # خروجی در samat-admin/dist ساخته می‌شود

# ۲. حالا نصاب ویندوز را بسازید
cd electron-app
npm install
npm run build:win
```

خروجی نهایی (نصاب `.exe`) در `electron-app/release/` قرار می‌گیرد.

## اجرای مستقیم بدون ساخت نصاب (برای تست)

```bash
cd electron-app
npm install
npm run start
```

## نکات مهم

- **هر بار که کد وب (`samat-admin`) عوض شد**، باید دوباره `npm run build` در پوشه‌ی اصلی و بعد
  `npm run build:win` اینجا بزنید — این پوشه فقط یک بسته‌بندی است، منبع واقعی کد همان
  پروژه‌ی وب است. (اسکریپت `build:win` خودش قبل از ساخت نصاب، آخرین خروجی `dist/` را کپی می‌کند —
  فقط نگذارید `dist/` قدیمی/build‌نشده باشد.)
- **آیکون سفارشی**: یک فایل `icon.ico` (حداقل ۲۵۶×۲۵۶) در همین پوشه بگذارید و `"icon": "icon.ico"`
  را زیر بخش `"win"` در `package.json` اضافه کنید؛ بدون آن، آیکون پیش‌فرض Electron استفاده می‌شود.
- **صادقانه**: چون محیطی که این پروژه در آن نوشته شده صفحه‌نمایش/GUI ندارد، نتوانستم واقعاً یک
  پنجره‌ی Electron را باز و از نظر بصری تست کنم — فقط سینتکس کد و منطق سرور محلی (که واقعاً
  فایل‌های build را با موفقیت سرو می‌کند) تایید شده است. لطفاً یک بار `npm run start` را روی
  ویندوز خودتان امتحان کنید.
- اپلیکیشن به اینترنت نیاز دارد (برای اتصال به Supabase) — این یک wrapper آفلاین نیست.
